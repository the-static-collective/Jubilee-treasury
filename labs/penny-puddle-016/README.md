# CAPABILITY LABORATORY-016 — MULTIPLE METHODS, DISCRIMINATING TESTS

**Jubilee Treasury × CONCORD-014 × GRAFT × native MOTIF research.**

**Research question:** When a useful transformation is absent from a community plan, can we test *different actual executable techniques*, reject an unsafe one, choose between safe tradeoffs, and return only independently checked evidence of the candidate's **local software capability**?

**Reality boundary:** Every story, hypothetical actor, asset and social obligation is fictional. Generating document HTML is an established software task; the three implementation strategies are hand-authored, not invented autonomously by MOTIF. No person is contacted and no actual assent, property license, creditor waiver, loan, payment, deployed code or human benefit is asserted.

## What's new compared with 015

015 implemented **one** local text-to-story-card technique to fill a missing CONCORD operator. 016 challenges the *method*, not merely the input: three independently written GRAFT candidates receive **identical** public invented examples, including a dangerous-looking HTML injection case and a multilingual display.

The receiving Jubilee verifier does not accept a self-described PASS. It recomputes acceptance on actual returned bytes and their deterministic replay.

| Method | Purpose | Expected observation |
|---|---|---|
| `unsafe-interpolation` | Deliberate red-team template that inserts raw text | **Fail** active-markup/escaping gate |
| `escaped-compact` | Minimal HTML escaping and print style | Pass mandatory safety; smaller measured HTML bytes |
| `accessible-print` | Reuse GRAFT's original 015 print-oriented, escaped story-card compiler | Pass safety and additional semantic presentation checks |

The red-team HTML exists **only as string evidence in a JSON report**, never as an executable `.html` file. No browser, identity/account or external site is used. This is not a complete HTML parser/security audit: in particular, the tests operate on a very small locked-down fixture and output grammar. A production web publisher would require actual DOM parsing, CSP, sandboxing, independent review and real-world vulnerability testing.

The verifier's mandatory checks examine:
- exact expected synthetic story text, escaped into the candidate's HTML;
- no active script/media/embed form tags, event-handler attributes or active remote reference syntax;
- original and replayed byte-for-byte equality and independently recomputed SHA-256;
- content and size budgets;
- no asserted money, actor authorization or production admission.

Additional inspectable presentation checks include CSS print support, document language, semantic card sections and a single heading. They are *proxies for document usability*, not a comprehensive accessibility certification.

## Two competing selection policies

- **Accessibility-oriented:** among completely safe, fitting options, prefer the method with the most measured presentation criteria; break ties by actual clean HTML UTF-8 length.
- **Smallest safe:** among completely safe, fitting options, prefer the smallest actual clean HTML; break ties by presentation criteria.

You can also supply a strict byte budget. Unlike invented point scores for human happiness, **actual output-byte size** is a reproducible resource measurement (although not a direct estimate of energy, CPU time or environmental footprint).

Both remain `PROPOSE_TESTED_TECHNIQUE_ONLY`. A result may improve the *toy planning vocabulary* but cannot complete an economic exchange. The separate scripted GRAFT→Jubilee run uses a source SHA pin so the same method contract is reproducible.

## How the real cross works

```text
JUBILEE-016 source-owned experiment contract
  → GRAFT-016 three real candidate functions
      → ordinary, attack and multilingual synthetic outputs
      → rerun each method byte-for-byte
      → write one JSON test-evidence document only
  → Jubilee-016 independently recomputes every hard gate
      → records failures; never erase unsafe candidate
      → chooses a policy-compliant passing technique
  → CONCORD-014 recomposes one new *conditional* route
      → awaiting human curator and landlord's actual choices
      → no real monetary, property, or legal consequences
```

The separately imported original **MOTIF-010 Scientist** selects discriminating interventions in a synthetic graph experiment within the GRAFT workflow. The scientist's findings are *not* used to override mandatory independent safety checks, and no production MOTIF service is updated. Its source remains pinned and read-only. Source checksums authenticate *bytes*, not authors or real-world competence.

## Run

Node.js 22+, dependency-free.

In Jubilee:

```sh
npm test --prefix labs/penny-puddle-016
node labs/penny-puddle-016/export.mjs > /tmp/jubilee-method-016.json
```

On GRAFT's `graft/capability-laboratory-016`:

```sh
node experiments/capability-016/cross.mjs --request /tmp/jubilee-method-016.json --out /tmp/graft-016-new-unused-dir
```

Back on Jubilee:

```sh
node labs/penny-puddle-016/verify.mjs --request /tmp/jubilee-method-016.json --kit /tmp/graft-016-new-unused-dir
```

GRAFT's CI checks out an exact Jubilee 016 commit, runs real candidate code, and calls Jubilee's verifier on the serialized report. It uploads the JSON report as an artifact so a reviewer can inspect failing cases, but **does not** publish any unsafe HTML.

## What has / hasn't been established

Established under the synthetic fixtures: distinct software implementations can behave differently on the same data; the receiving code can reject one without automatically trusting GRAFT's assertions; a resource budget can change the chosen method; the resulting checked technique can be represented as a *potential* new CONCORD operator.

Not established: a general algorithm that invents software without hand-written candidate methods, comprehensive output safety, empirical learning beyond the tiny source-pinned scenario, practical real-world economic value, actual community consent or performance, intellectual-property rights, any real settlement, proof of historically novel mathematics, or an authenticated trust channel between projects.

**Rule:** *A failed experiment is a useful scar. A passing local method is evidence of local behavior. Neither grants authority over people or property.*
