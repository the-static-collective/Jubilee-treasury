# INTE-GREAT 001 — The Great Return
Portable Jubilee operator entry point, not a payment system or an autonomous rescue engine.

## Open
Extract the entire ZIP to a trusted local folder. Open `inte-great/index.html` in a current browser; the local casework HTML has no external dependencies. The packaged rehearsal HTML is generated by invoking the native engines. No Node installation is needed to read that report or use compatible local casework.

For source checkout / repeatable rehearsal, install Node 22.16+ from the official Node website, then run from repo root:
```sh
node --experimental-strip-types inte-great/run.mjs
node --experimental-strip-types inte-great/run.mjs --html > inte-great/rehearsal.html
```
No dependency install or external account required for this selected runner. It imports ANGEL CIRCLE, ANCHOR, QUESTION, CONCORD and EXODUS directly. RELAY and the earlier question/satisfaction engines are invoked by those source modules. Other historical lab packages are included for study, with their own instructions; some tests require separately source-pinned MOTIF.

## Real coordination vs research
Use the existing EXODUS 004 local casebook for non-sensitive real coordination. Keep independent encrypted copies and verify downloads; do not share passwords or put private case information in the repository. Research engines operate only on fixed invented scenarios and do not read your casebook. A hypothetical sponsor, proposal or receipt does not prove funding, agreement, or entitlement. No automatic transfer between the fictional research and real case records. No payment rails, publishing, outreach, accounts, or hosted collaboration in this package. No native Android installer; file-based browser compatibility on the user's device remains unverified.
