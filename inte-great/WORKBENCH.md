# INTE-GREAT 002 — Living Workbench
Open the generated workbench.html (build: node inte-great/build-workbench.mjs). It is the original offline casework HTML plus a bounded browser-side review adapter and the source-owned CONCORD-014 composer, with no remote dependencies. Use actual non-sensitive records, manually classify source-linked supported claims, enter a reported remaining USD amount and select distinct offer records. The native composer is given abstract rule/role placeholders, never personal data or verified willingness. The adapter ranks missing questions by number of candidate routes affected, not empirical probability or human value. It searches up to 12 selected offers for a hypothetical covering subset; duplicate source references are rejected, but different sources can still refer to the same donor/pledge. Check availability, overlap, restrictions, terms and real authority independently. It does not count reported receipts as additional available money. No output authorizes payment, outreach, publication, consent, ownership or settlement. Operator can explicitly append a suggested question as a task to the same unchanged local case. Annotations and candidate reports are transient, not stored as authoritative case evidence. Save the encrypted casebook as usual. No automatic extraction of legal facts, multi-currency, generic user-authored agreement grammar, remote collaboration or real identity data. Four authored route families: written extension, sponsorship, local bridge, guarantee/alternative; not exhaustive. Browser acceptance on actual devices remains a separate test.
