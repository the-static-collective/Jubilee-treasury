# EXODUS 004 — Local Casework Desk
Open casework.html in a trusted browser with Web Crypto (download the HTML; do not use an online HTML preview for private records). Offline, no installation, no server and no network requests. Create a new book, use a unique long passphrase, add case aliases, source references, claims, reviews, dated tasks and conditional offers. Save encrypted JSON after each session; reopen to verify the downloaded file before locking. No automatic saving; changes stay in memory until encrypted download. Do not include vulnerable persons' identities, actual documents, bank credentials or payment instructions. Use opaque references to separately secured evidence. Local human review is a recorded opinion, not independent verification or legal authority. No sharing or multi-user authentication; the existing Steward Desk remains the proposed hosted owner boundary. This is usable for real non-sensitive coordination, not a security-audited evidence vault. No actual case data in repository.

## Scope / limitations
Browser memory and OS downloads may be observable on compromised/shared devices. Password-derived AES-GCM with 600k PBKDF2 iterations, fresh salt and IV. No recovery if passphrase lost, no secure erase, no rollback protection or independent audit signature; a user can replace an entire book. No browser/Android acceptance tested yet. The casebook records reports, not verified funds. No documents uploaded to cloud, no real contact, payments or public intake changes. Run node --test ops/exodus-004/casework.test.mjs.
