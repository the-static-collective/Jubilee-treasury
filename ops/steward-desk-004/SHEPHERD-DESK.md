# EXODUS 005 — The Shepherd's Desk
Parent: merged EXODUS 004, 7d5f244de6e592b65ac61224349351fa4919487b.
## Operation
After verified CI and redeploy of existing jubilee-steward-desk Worker from ops/steward-desk-004, sign in at https://steward.abundent.org/ and choose Casework Desk. Every casework asset requires the original owner-only StaticID check and a current Jubilee desk RPC grant. No new OAuth client, database table, public API, grant or payment capability.
Open or create local encrypted casebook, select the intended case, read current desk candidates, and explicitly add each source plus open task. CONCORD questions are the existing read-only source projection, not a new financial proposal engine. Imported items never change the server queue. Save encrypted file and verify the download before locking.
Correspondence import: local JSON schema jubilee.correspondence-candidates/v1 with items each containing only ref (gmail: followed by 12–32 hexadecimal characters) and category (reply, outreach, delivery). No bodies, addresses, attachments, credentials, automatic mailbox reads or outbound messages. Source references are reviewed individually and linked to task IDs. No real records in Git.
## Scope and remaining gates
Local encrypted file, not synchronized cloud case storage. Authenticated owner only; Paula requires a separately scoped, independently authenticated collaborator grant and explicit sharing consent. Do not widen owner check or reuse owner tokens. No arbitrary access to a case based on a file or referral. Hosted browser smoke, exact deployed version and owner read require confirmation. Candidate text is source-reported, not verified; no automated payment, publication, or action. Generated casework assets preserve exact offline scripts; regenerate when parent changes. Existing grant expiry is unchanged.
